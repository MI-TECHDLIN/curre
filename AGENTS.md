# Project agent memory

This file is the project's committed home for project-intrinsic agent knowledge: build, test, release, architecture, and sharp-edge notes that should travel with the code.

- The Android launcher channel contract lives in
  `android/app/src/main/kotlin/com/mitech/curre/MainActivity.kt`; its Dart
  adapter and pure door-order policy live in `lib/doors/`. The production
  door inventory, fallbacks and phone-check matrix live in `docs/doors.md`.
- The permanent Android namespace and application ID are `com.mitech.curre`.
- Release signing reads `android/key.properties` (gitignored; never commit a
  keystore). Copy `android/key.properties.example` for the keytool command
  and expected keys. `android/app/build.gradle.kts` fails the build with a
  clear message if a release task runs without it; release never falls back
  to the debug key. CI runs `flutter analyze`/`test`, an Android debug
  build, and server `pytest`/`ruff` on PRs; it doesn't need signing since
  it only builds `--debug`. The workflow lives at `docs/ci-workflow.yml`,
  not `.github/workflows/`, because the crew's push credential lacks
  `workflow` scope -- copy it over from an account that has it to enable CI.
- Screen-facing notification, speech-input, Home-refresh and home-screen
  settings plumbing lives in `lib/platform/`; local reminders, their
  per-type/quiet-hours policy and the tap/action intents routed in
  `lib/main.dart` are in `local_notifications.dart`.
- Voice typing is Whisper tiny run on the phone by `sherpa_onnx`, a
  one-time download pinned by SHA-256: `SpeechInputService`
  (`lib/platform/speech_input.dart`) opens the voice sheet
  (`lib/app/voice_sheet.dart`, bound in `main.dart`); the model store, mic
  and engine are `lib/platform/voice_*.dart`. Tests use
  `test/support/voice_fakes.dart` (`fakeController` does), since the real
  store needs path_provider.
- Hidden-app foreground checks and notification quieting use the Android
  services beside `MainActivity.kt`; their access adapters and pure policies
  live in `lib/platform/gentle_intercept.dart` and `quiet_notifications.dart`.
- The launcher icon, splash and notification art are code-drawn: vector
  masters in `android/app/src/main/res/drawable/`, PNG fallbacks regenerated
  by `tool/generate_brand_assets.py`.
- User-facing words stay plain ("Hidden apps", "Bring back", "Why now?",
  "plan"): `test/copy_test.dart` fails on any banned term in a `lib/` string
  literal or on a rendered screen; the list is in
  `test/support/copy_rules.dart`.
- Onboarding's steps live in `lib/app/onboarding_screen.dart`, its scenes in
  `lib/app/onboarding/`. Scene props are Fluent Emoji (MIT) drawn as vectors
  from `lib/design/art/fluent_props.dart`, generated by
  `tool/build_fluent_props.py`; regenerate rather than hand-edit.
- Validate Flutter changes with `flutter analyze` and `flutter test`.
- The design system (tokens, theme, widgets) lives in `lib/design/`; import
  `design/design.dart`. The debug gallery (`lib/gallery/`) renders every
  widget and preview screen in light and dark. Change a Curre text style's
  weight with `.weight(w)`: `copyWith(fontWeight:)` leaves the variable
  font's `wght` axis where it was. Human profile art and its unnamed picker
  live in `lib/design/widgets/avatar*.dart`; the selection persists as
  `Settings.avatarId`.
- Ask for icons through `CurreGlyph` (`lib/design/widgets/curre_glyph.dart`),
  not `SolarIconsBold` directly: solar_icons 0.2.0's Bold font drops some
  inner cut-outs (question mark, info dot, warning shield, clock hands), and
  the mapping there uses only glyphs checked by eye.
- The backend (`/v1/plan`, `/v1/unlock` over one `clocked-sdk` Pipeline call
  each) lives in `server/`; see `server/README.md` for setup, tests and the
  endpoint map. Validate backend changes with `server/.venv`'s `pytest` and
  `ruff check server`.
- Phone-owned models, sessions, visibility, grants, the typed backend client
  and local persistence live in `lib/core/`; its client reads
  `CURRE_API_BASE_URL` and `CURRE_APP_KEY` from `--dart-define`.
- Seven-day, phone-owned Later items and their ordering policy live in
  `lib/core/later.dart`; `lib/app/later_shelf_card.dart` renders them after a
  plan, and `/v1/later` makes one Rerank call with newest-first fallback.
- Prooflight's evidence, Curre-day, streak and cloud-day rules live in
  `lib/core/proof.dart` (pure: the summary is rebuilt from records, never
  stored), the completion sheet and sunrise moment in
  `lib/app/completion_sheet.dart`, and `/v1/proof` is the one-pipeline judge:
  Decide still requires a specific completion, while Verify only vetoes a
  clear contradiction (an ordinary new detail is `not_stated`). Protect spans
  from unlock/proof are applied to History copies by `lib/core/redaction.dart`;
  a missing or unusable Protect result deliberately keeps the original text.
  A note counts only with a `TaskTrace` recorded when its task started
  (`openPlanDoor`, `startOfflineTask`); pending notes keep their plan's day.
- The check-in card's water is core `DayProgress` (`lib/core/progress.dart`),
  which counts `DoorUse`s: a screen that opens a plan's app must call
  `CurreLocalStore.recordDoorUse`, or the water never rises. Motion (Peek,
  `LiveSky`, `RisingWater`) belongs to the check-in and moments of choice,
  never Home, and must hold still under reduce-motion.
- clocked-sdk 0.7.0 response shapes are easy to get wrong: Decide answers
  are under `result["answers"]` (a `choice` answer's label is `["choice"]`,
  a `multiselect` answer's labels are `["selected"]`); Fill and Extract
  answers are both under `result["fields"]`, where a Fill `choice` or
  `multiselect` field's chosen value(s) are `["value"]` instead. See the
  module docstring in `server/app/clocked_pipeline.py` for the full set.
  Guard quote offsets index the server's composed text, not the user's
  reason: highlight with `literalSpanInSource` (`lib/core/span.dart`).

## Maintaining this file

Keep this file for knowledge useful to almost every future agent session in this project.
Do not repeat what the codebase already shows; point to the authoritative file or command instead.
Prefer rewriting or pruning existing entries over appending new ones.
When updating this file, preserve this bar for all agents and keep entries concise.
